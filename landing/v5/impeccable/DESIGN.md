# Sara v5 · Impeccable · Monochrome Documentary

Documented from the built page.

## World
Documentary restraint. One photograph carries the feeling; everything after it is plain record: numbers, four steps, a transcript, a ledger.

## Colour
| Token | Value | Role |
|---|---|---|
| `--white` / `--grey-bg` | `#ffffff` / `#f2f2f0` | Section grounds, alternating |
| `--ink` | `#161615` | Text, rules, closing band |
| `--mute` / `--neutral` | `#6a6a67` / `#8d8d89` | Secondary text; the single "Works with" colour |
| `--hair` | `#dcdcd8` | Hairlines |
| `--red` | `#b3261e` | Thread red: CTA and step numerals only |

## Type
- **Schibsted Grotesk** 400–800, tight tracking (−0.04 to −0.06em) for display.
- **Red Hat Mono** 400/500 for figures, times and the transcript. Tabular figures scoped to numeric elements only (the display face tabulates punctuation).

## Grid and shape
4/8 split on desktop, hairline rules, square corners; the CTA is the only pill.

## Motion
The photo develops in (fade and slight scale), then the headline lines. Steps and transcript lines enter in reading order. Nav is transparent on the photo, solid after it.

## Hero slot
`.hero-photo` fills the viewport (capped 600–1100px), grayscale, 16:10 desktop / 3:4 phone; headline bottom-left over a scrim.
